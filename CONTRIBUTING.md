# Contribuer · Contributing

Merci de votre intérêt pour Génothèque.

- **Une donnée fausse, une traduction maladroite, une idée** : ouvrez une [issue](https://github.com/jimmydaviddarly-blip/genotheque/issues) ou écrivez à studio.nebulis@gmail.com. Pour une donnée, indiquez la fiche (le lien partagé suffit) et la base concernée : souvent, l'erreur vient de la base d'origine, et c'est là qu'il faut la signaler.
- **Du code** : les propositions (pull requests) sont étudiées au cas par cas. Ouvrez d'abord une issue pour en parler, surtout pour une nouvelle base ou une nouvelle page.

Les contributions sont publiées sous la même licence que le projet, **AGPL-3.0-or-later** (voir [NOTICE.md](NOTICE.md)). Le nom, le logo et l'icône de Génothèque restent réservés à son auteur.

Trois règles ne bougent pas :

1. Consultation seulement : pas de lecture de données génétiques personnelles, pas de calcul de risque.
2. Toute donnée externe passe par `esc()` avant d'entrer dans la page.
3. Tout texte de l'interface existe en français et en anglais (`npm run i18n` liste les oublis).

*Bug reports and ideas are welcome as issues or by email. Code contributions are considered case by case: open an issue first. The app stays consultation-only, escapes all external data, and keeps every text in French and English.*
